### build.mjs 新增内容

- `writeResources()`：**configure 之前**为六个应用各写一份 `cpp/build/rc/<app>.rc`；**内容相同则完全不重写**（保住 mtime → ninja 不会重编 RC 对象、不会重链）。这是幂等的关键。
- `findIcon()`：优先 `installers/packaging/icons/<app>.ico`，回退仓库根 `icons/<app>.ico`；两处都缺 → 抛错（exit≠0）。
- `rcText()`：`1 ICON` + `1 VERSIONINFO`；ICON 路径写成绝对正斜杠路径（windres 以 cwd=`cpp/build` 解析路径，而非 .rc 所在目录）；`FILEVERSION/PRODUCTVERSION = 1,0,0,5`（`1.0.0-pre5` 的第 5 个 pre）；StringFileInfo：`CompanyName=Infinity.Inc`、`FileDescription/ProductName=<APPS.label>`、`FileVersion/ProductVersion=1.0.0-pre5`、`InternalName/OriginalFilename`。
- `assertRCCompiler()`：配置后读回 `CMakeCache.txt` 的 `CMAKE_RC_COMPILER`，断言其 basename 是 `windres(.exe)` 且文件存在；否则报错。
- `resourceTypes()`：纯 JS 解析 PE（DOS→可选头→数据目录 2→节表映射→资源目录根），返回资源类型 id 列表；`main()` 要求每个 exe 同时含 `3` 与 `14`，否则 **throw → exit≠0**。函数已导出（`export { main, resourceTypes }`）供负向测试复用。
- 版本/公司可用 `INC_VERSION` / `INC_COMPANY` 覆盖，默认值与 `package.mjs` 的 `1.0.0-pre5` 一致。
- **导入表审计（`imports()`/`audit()`/`SYSTEM_DLLS`/大 maxBuffer）未改动**，资源对象不引入任何 DLL。

### CMakeLists 新增内容

```cmake
enable_language(RC)                       # 资源由 windres 编译，不由 C++ 编译器编译
set(INC_RC_DIR ${CMAKE_CURRENT_BINARY_DIR}/rc)
# foreach(app ...) 内：
set(INC_RC_SRC ${INC_RC_DIR}/${app}.rc)
if(EXISTS ${INC_RC_SRC})
  add_executable(${app} apps/${app}/main.cpp ${INC_RC_SRC})

  message(WARNING "${app}: ... run tools/build.mjs")
  add_executable(${app} apps/${app}/main.cpp)

```

1. **文档未同步**（不在本任务作用域）：`docs/RELEASE-v1.0pre5.md` §7（各应用"可执行文件资源段需在 C++ 链接时用 windres 加 .rc"）与文末"可执行文件资源段图标（windres .rc）未接入"、`cpp/README.md` §Building/环境说明 需要更新为"已接入"。
2. **版本号默认值**：`1.0.0-pre5` 同时硬编码在 `build.mjs`（新增）与 `package.mjs`/`manifest.mjs` 的默认值里；下一个 pre-release 需要一起改，或用 `INC_VERSION` 覆盖（注意 `build.mjs` 的 RC 用的是同一个环境变量口径）。
3. **图标来源**：优先 `installers/packaging/icons/<app>.ico`（当前该目录未被 git 跟踪），回退到已跟踪的仓库根 `icons/<app>.ico`（两者当前字节/sha256 完全相同）。若将来清理 `installers/`，构建仍可用根目录图标。
4. **图标帧数**：每个 .ico 含 21 帧、3 个 group 条目，exe 里 RT_ICON 21 条 —— 属图标自身内容，不是重复注入。
5. **ING 无独立差异化**：ing 用同一套 rc 生成逻辑（图标 `ing.ico` + 产品名 Infinity Games + 公司 Infinity.Inc），未做单独定制；若要求不同公司/产品名，需要再参数化。
6. `release-assets.json` 的 `generated` 时间戳随 `manifest.mjs` 运行刷新；其余字段由磁盘字节计算，不会漂移。
7. 证据文件（均在 git 忽略的 `cpp/build/`）：`icon-rc-before.json`、`icon-rc-evidence.txt`、`icon-rc-build.log`、`icon-rc-build2.log`、`icon-rc-build3.log`、`icon-rc-package.log`、`icon-rc-manifest.log`、`pe-resources.ps1`、`icon-rc-rescheck.mjs`、`icon-rc-evidence.ps1`。
