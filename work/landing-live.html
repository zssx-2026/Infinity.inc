两个入口，一套系统

Infinity Studio 是安装一切的入口：它自己会去取已发布的安装包，校验后静默装上。Infinity Server 是机架控制台，用来跑与看这条流水线。两个都是自包含的 Windows 安装包。

下载前会先进入一次人机验证页，验证通过后由 Cloudflare 302 跳转到安装包。地址可以换、文件可以重发，页面不用跟着改。

怎么用

先装 Infinity Studio。打开后在「在线安装」里刷新目录，选要装的产品点安装：它会下载安装包、核对 sha256、再以 /S 静默安装到当前用户目录，不需要管理员权限，也不会弹第二个安装向导。
